# 车站字典与电报码

[文档目录](README.md) · [项目首页](../README.md)

## 后端准备

更新后端后执行 `php think ticketing:schema`。管理员在后端工作台「机构管理 → 车站字典」为导入站点配置：可见性、一个已有运营企业代码、全系统唯一的三个英文字母电报码、中英文站名、自由输入的一级和二级行政区。

未配置车站默认隐藏，因此新升级后车站列表为空时，应先配置并启用车站。tTRS 通过出票方的公共车站接口读取目录，字典编辑在管理员工作台完成。重新导入 MTR 保留人工配置。

## 键盘售票

1. Ctrl+O 连接后，客户端自动读取所有分页的可见车站。
2. F3 / F4 打开选择窗口，输入电报码（如 `xay`）、中英文站名、拼音或完整站 ID。
3. 表格显示电报码、中文名、英文名、归属企业、两级行政区和维度，Enter 选择。
4. F12 查询区间时优先传电报码；取入待办时保存电报码、班次 ID 和上下车站序，Alt+N 出票。

站序保留用于同一班次重复经过同一车站时的精确匹配。车站归属企业与班次承运企业分别显示，不据站点归属推断承运方。

管理员修改目录后，可在选择窗口按「服务器查询」刷新匹配列表，或重新连接刷新全部目录。服务器查询支持中英文名和电报码；拼音由客户端本地匹配。

## 隐藏车站与恢复

隐藏站不会出现在新的公共目录中。已打开窗口可能仍有缓存，后端会在查询及出票时检查最新可见性并拒绝隐藏站。未提交待办不会绕过后端限制，需重新选择可见站点查询。

已提交订单的重试始终保留原幂等键和原参数，避免重复出票。已有客票可继续查票和退票。票面和 TXT 导出优先使用后端返回的车站字典，因此车站隐藏后仍能显示中文名和电报码。

兼容旧后端缺少字典字段或分页 `total` 的目录，查询沿用站 ID；票面按本地目录、旧站名和站 ID 依次回退。旧后端没有可见性管理时，无法应用新字典的限制。

## 验证

`python tools/check.py` 包含字典检索、分页完整性、隐藏站票面及键盘选码后保存出票待办的测试。`python tools/live_backend.py` 使用独立临时站点和字典，在真实 PHP API 上验证小写电报码选站、区间查询、出票、同键重试、查票和退票，结束后清理并检查所有夹具。
