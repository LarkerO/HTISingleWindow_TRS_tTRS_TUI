# tTRS 0.4 更新

- 底部改为三行实时运行面板：本地时区时间、本张及下一张票号、会话操作次数、服务器连接、HTTP 往返、已验签处理耗时、客户端 CPU 和 RSS。
- 原后端在出票时随机分配票号；下一张显示“出票时生成”。待确认订单不被误标为尚未出票。
- 时钟和进程资源每秒更新，后台健康探测每 10 秒一次、超时 3 秒；不会计入业务操作次数，也不会覆盖服务端签名处理耗时。
- 本地演示不显示虚假的远端网络指标；底部不再显示原演示测试文案。
- 改进小窗口布局，避免状态栏把操作按钮挤出可见区域。ASCII 边框改为可响应布局的样式规则。
- README 调整为独立 Git 仓库的安装、连接、操作及验证说明。依赖通过 uv.lock 和 Python 3.12 固定。
